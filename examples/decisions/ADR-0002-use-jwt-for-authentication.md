# ADR-0002 — 使用 JWT 进行身份认证

> 日期: 2024-01-15  
> 状态: `proposed`  
> 决策者: @architect

---

## 上下文

系统需要安全的无状态身份认证机制。
需要一种可扩展的 token 方案。

---

## 决策

使用 JWT（JSON Web Token）配合 RS256 签名算法。

---

## 备选方案

| 方案           | 优点                   | 缺点               | 结论       |
| -------------- | ---------------------- | ------------------ | ---------- |
| JWT + RS256    | 无状态、可验证、跨服务 | Token 不可撤销     | **采用**   |
| Session Cookie | 简单、可撤销           | 有状态、不利于扩展 | 拒绝       |
| OAuth2         | 标准化、第三方登录     | 复杂度高           | 未来可组合 |

---

## 后果

### 正面
- 无状态认证，易于水平扩展
- 非对称签名，公钥可分发给微服务验证

### 负面
- Token 签发后无法立即撤销（需要黑名单机制或短过期时间）

### 风险
- 密钥泄露 → 通过密钥轮转缓解

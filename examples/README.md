# 示例

> 本目录包含使用 OpenSpec 框架的示例，**不属于框架本体**。
>
> 复制框架到你的项目时，**不需要复制此目录**。

---

## 示例列表

| 示例 | 说明 | 展示内容 |
|------|------|----------|
| `user-auth/` | 用户认证功能 | 完整的功能规格（含验收标准、接口定义、边界情况） |
| `example-feature/` | 基础功能骨架 | 最小化的功能规格结构 |
| `decisions/` | JWT 认证 ADR | 完整的架构决策记录（含备选方案） |
| `patches/` | IPv6 解析修复 | 补丁工作流示例 |

---

## 如何使用

查看这些示例来了解如何填写框架的模板：

1. `user-auth/spec.md` — 对照 `spec/features/template.md` 查看
2. `user-auth/tasks.md` — 对照 `spec/features/tasks-template.md` 查看
3. `decisions/ADR-0002-*.md` — 对照 `spec/decisions/ADR-template.md` 查看
4. `patches/fix-ipv6-parse.md` — 对照 `changes/patches/patch-template.md` 查看

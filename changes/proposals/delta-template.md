## Delta 变更

使用 `[ADDED]`、`[MODIFIED]`、`[REMOVED]` 标记描述规格的增量变更。
每个变更必须指明**目标节（Section）**和**具体内容**。

### [ADDED] 新增内容

<!-- 列出新增的规格内容，指明添加到哪个节 -->

```
目标节: ## 设计
内容:
  - 新增批量导出 API，支持 CSV 和 JSON 格式
  - 导出任务异步执行，通过 WebSocket 通知完成
```

### [MODIFIED] 修改内容

<!-- 列出修改的规格内容，指明原内容和新内容 -->

```
目标节: ## 接口
原内容: GET /api/export → 同步返回数据
新内容: GET /api/export → 返回任务 ID，异步处理
原因: 大数据量导出会超时，改为异步模式
```

### [REMOVED] 删除内容

<!-- 列出删除的规格内容，指明删除原因 -->

```
目标节: ## 接口
删除内容: POST /api/export/sync — 同步导出端点
原因: 统一使用异步导出，同步端点废弃
```

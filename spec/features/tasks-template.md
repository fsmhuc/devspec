## 状态说明

- `not-started` — 尚未开始
- `ready` — 依赖已满足，可以开始
- `in-progress` — 正在进行（同时只有一个）
- `blocked` — 被依赖项阻塞
- `review` — 等待审查
- `done` — 已完成
